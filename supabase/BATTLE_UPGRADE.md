# 40 人联机对战升级

## 上线顺序

1. 等待当前比赛结束。在 Supabase SQL Editor 执行本目录的 `upgrade_battle_40_players.sql`。该迁移可重复执行，不清空学生、成绩或历史赛程。
2. 确认迁移执行成功后，再发布新版网页（`arena.js`、`battle-engine.js`、`cloud.js`、`styles.css`、`sw.js`）。不要只发布网页而跳过数据库升级。
3. 刷新老师和学生网页，创建一个新房间进行验收。旧的已开始房间保留旧赛程，避免打乱既有对手和成绩。

## 新规则

- 房间最多 40 位学生。数据库在同一房间锁内检查人数并加入学生，旧客户端直接写入也受上限约束。
- 仍需要 2–40 的偶数人数开始：34 人首轮 17 场，40 人首轮 20 场，首轮人人参战。
- 后续奇数人数轮次最多一人轮空，优先安排此前轮空次数较少的学生，尽量避免连续轮空；不会重新抽签已有赛程。
- 4 人半决赛的两名败者进行季军赛。若剩 3 人，一人轮空入决赛，实际半决赛的败者获得季军。两人参赛只产生冠亚军。
- 开赛时先冻结名单；正式赛程和服务器倒计时一起提交。断网后可以重试，不会重复创建赛程，也不会因迟到的重试直接结束第一轮。
- 已在房间的学生可以重新进入；开赛后不再接受新学生。

## 老师比分看板

- 每场卡片显示本轮得分、生命条、胜负及作答次数，无须加载 3D 画面。
- 轮次选择器可查看当前实时比分或此前每轮的结束比分、血量。
- 全体学生战绩表保留所有参赛学生，分别显示所选轮得分、血量、当前状态和全赛程累计得分。
- 轮空或该轮未参赛显示 `—`，不虚构 0 分或生命值。新一轮重置本轮分数/血量，不清空此前记录和累计分数。
- 订阅 Supabase Realtime；页面前台每 3 秒补充读取，切回页面立即重同步。网络延迟/失败会标明显示的是上次数据。
- 使用数据库时间校准比赛时钟，避免老师/手机时钟差异导致已保存的答题不计分或过早结束比赛。

## 数据库改动

- 新增 `battle_rooms.tournament_version`，历史房间默认 0，不改写历史事件。
- 新增服务器时间、加入房间、冻结名单、原子提交首轮赛程 RPC。
- 玩家身份和所属房间不能被 UPDATE 更改，防止绕过人数上限；正常状态更新保留。
- 房主老师和本房间学生可读取完整的本房玩家与答题事件；无关房间不可读。将旧 `battle_players_write FOR ALL` 拆分为 INSERT/UPDATE，避免它意外绕过 SELECT 限制。
- 若存在 `supabase_realtime` publication，确保三个对战表已加入。
- 如果线上另外创建过自定义宽泛 RLS 策略，应另外审计；迁移不擅自删除未知策略。

## 测试与上线验收

在项目根目录执行 `pnpm test:battle`（或分别运行三个 `scripts/test-battle-*.mjs` 测试脚本）。云端集成测试使用内存 mock，不写真实数据库。

实际 SQL/RLS 测试另用隔离的 PGlite 环境，安装于被 Git 忽略的 `.temp/battle-sql-check`，不改项目依赖：

```powershell
New-Item -ItemType Directory -Force .temp/battle-sql-check
pnpm --dir .temp/battle-sql-check add @electric-sql/pglite@0.5.10
pnpm test:battle:sql
```

本次验证通过：15 组引擎测试、18 项云端 mock 回归、8 项老师看板测试及 10 项 PostgreSQL/RLS 运行检查。包含 2–40 全部偶数人数赛程、34/40 人完整晋级、设备时间偏差、开赛中断重试及历史成绩。数据库测试使用单连接，**不是 40 人真实网络并发压测**。

浏览器使用实际看板代码及隔离的模拟房间，检查 40 人/20 场显示、作答更新分数和血条、切换历史轮次、刷新恢复与同步失败提示；没有连接真实学生数据。

桌面及 390×844 手机宽度均已检查：比赛卡片、分数和生命条可读，手机页面没有横向溢出；全体成绩表可以在表格区域内横向滚动。此项不是实体手机或 40 台设备在线压力测试。

正式环境还应进行一次老师账号＋学生账号验收：入房、开赛、学生作答后老师分数/对手血条更新、进入下一轮、切回历史轮次、刷新恢复。模拟测试不能替代真实网络及实际 RLS 的上线确认。

数据库升级失败时，网页会明确提示缺少迁移，不会降级到不安全的客户端人数计数。回退网页时可保留数据库迁移；不要通过删除历史赛程、学生或事件来回退。
