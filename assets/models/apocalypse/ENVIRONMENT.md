## Runtime preparation

The 1K source glTF files were converted to self-contained GLB, with opaque material images recompressed as 1024-pixel JPEG. The fence wire's separately published opacity map was restored into its base-color texture as RGBA PNG, with alpha masking enabled so openings remain transparent. Geometry was welded, deduplicated, and selectively simplified. All meshes and original PBR materials remain modeled source assets; they are not procedural substitutes. The modular fence was separated into a panel and an assembled gate. Every model is centered horizontally with its base at Y=0. No Draco or meshopt runtime decoder is required.

The 1K HDR panorama is 1,827,366 bytes and provides environment lighting. The background JPEG uses the original photographer's tone-mapped panorama, resized from 8192 × 4096 to 4096 × 2048 for a clearer backdrop. Ground color, normal, and roughness images total 269,518 bytes and represent approximately 4.5 × 4.5 metres per repeat. The normal map follows the OpenGL convention. The covered car's long axis is Z; the tyre stands upright in the XY plane. The fence panel lies in the XY plane.

The GLBs have a `GroundedAsset` wrapper. Fence descendants preserve source names: `modular_chainlink_fence_double`; gate descendants are `modular_chainlink_fence_door_frame`, `modular_chainlink_fence_door_gate`, and `modular_chainlink_fence_door_latch`.

## Rebuilding

`scripts/prepare-arena-environment.mjs` downloads the original sources using Poly Haven's public metadata API, verifies their published MD5 checksums, and repeats the optimization. Invoke it with `--tools` pointing at a separate directory containing the optional build tools; package names and original versions are documented in the script. No additional runtime dependencies are needed by the website. Use `--sources` to select a download cache and `--output` to write a verification build elsewhere. A verification rebuild matched the generated assets byte for byte. Khronos glTF Validator reported no errors in any environment model; its only warning is that tangent vectors are generated by the renderer for normal mapping.

## Blender-authored scene and render

The previous browser arena loaded `blender-wasteland.glb`, not individually positioned runtime props. `scripts/build-blender-arena.py` rebuilds that retained scene in Blender 4.2.9:

- Imports the licensed scanned car, road barriers, barrels, tyres and chain-link panels once, sharing mesh and material data between repeated objects.
- Models thick, irregularly broken warehouse walls, bevelled I-section steel girders, exposed reinforcement and fractured concrete debris. These are editable Blender meshes, not a flattened background image.
- Uses the scanned concrete color, normal and roughness textures on the modeled ruins and uneven ground. Bevels, weighted normals and export triangulation preserve edge highlights.
- Bakes a 2048-pixel ambient/contact occlusion map in Cycles. Ground UV0 repeats the surface textures; UV1 holds the independent, nonrepeating bake. The bake intentionally excludes animated characters, whose shadows are calculated in the browser.
- Exports embedded PBR textures and tangent vectors as a decoder-free GLB; opaque images use JPEG while the fence retains PNG transparency.
- Renders a 1440 × 900 Cycles reference with 48 samples, denoising, HDR lighting, soft area lights and AgX. The editable `.blend` packs its textures and includes the two animated characters for preview.

Run `blender --background --factory-startup --python scripts/build-blender-arena.py` from the repository. Outputs: the production GLB above, plus `.temp/research/blender-arena/arena-rendered.blend`, `arena-blender-preview.png`, and `ground-contact-ao.png`. `ARENA_SKIP_BAKE=1` reuses an existing AO bake only when the scene layout has not changed; `ARENA_SKIP_RENDER=1` skips the final preview render.

The browser remains interactive Three.js/React Three Fiber, using matching AgX tone mapping, HDR reflections, per-pixel metallic/roughness, baked ground occlusion and dynamic softened shadows. It does **not** run Cycles path tracing on students' phones, and the offline reference is not a promise of pixel-identical browser lighting. The teacher's multi-match scoreboard still loads no 3D assets.
