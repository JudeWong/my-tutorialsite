## Runtime preparation

The 1K source glTF files were converted to self-contained GLB, with opaque material images recompressed as 1024-pixel JPEG. The fence wire's separately published opacity map was restored into its base-color texture as RGBA PNG, with alpha masking enabled so openings remain transparent. Geometry was welded, deduplicated, and selectively simplified. All meshes and original PBR materials remain modeled source assets; they are not procedural substitutes. The modular fence was separated into a panel and an assembled gate. Every model is centered horizontally with its base at Y=0. No Draco or meshopt runtime decoder is required.

The 1K HDR panorama is 1,827,366 bytes and provides environment lighting. The background JPEG uses the original photographer's tone-mapped panorama, resized from 8192 × 4096 to 4096 × 2048 for a clearer backdrop. Ground color, normal, and roughness images total 269,518 bytes and represent approximately 4.5 × 4.5 metres per repeat. The normal map follows the OpenGL convention. The covered car's long axis is Z; the tyre stands upright in the XY plane. The fence panel lies in the XY plane.

The GLBs have a `GroundedAsset` wrapper. Fence descendants preserve source names: `modular_chainlink_fence_double`; gate descendants are `modular_chainlink_fence_door_frame`, `modular_chainlink_fence_door_gate`, and `modular_chainlink_fence_door_latch`.

## Rebuilding

`scripts/prepare-arena-environment.mjs` downloads the original sources using Poly Haven's public metadata API, verifies their published MD5 checksums, and repeats the optimization. Invoke it with `--tools` pointing at a separate directory containing the optional build tools; package names and original versions are documented in the script. No additional runtime dependencies are needed by the website. Use `--sources` to select a download cache and `--output` to write a verification build elsewhere. A verification rebuild matched the generated assets byte for byte. Khronos glTF Validator reported no errors in any environment model; its only warning is that tangent vectors are generated by the renderer for normal mapping.
